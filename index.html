Game dev shipped.

🚀
Spicy Invaders
C++ · SFML · Raw OOP · No STL

Full arcade space shooter built from scratch. Progressive enemy waves, pixel-perfect collision, three boss fights with unique attack patterns, three power-up types (EMP mechanic), spritesheet-rendered explosions, and a complete audio engine. Every class is mine.

GitHub ↗ Demo
🍬
Goated Candy
C++ · SFML · Match-3 · Gravity Sim

Candy Crush clone on an 8×8 grid with a smart matching algorithm, real gravity simulation, cascading chain reactions, and four special candy types including a Color Bomb. Board refills, animations — handwritten. No engine shortcuts.

GitHub ↗ Demo
🔩
4-bit Processor
Digital Logic · LogicWorks · 74LS TTL ICs

Designed and built a working 4-bit processor supporting an 8-instruction ISA using 74LS-series TTL ICs in LogicWorks. A semester project that went beyond the spec — built to actually run programs.
