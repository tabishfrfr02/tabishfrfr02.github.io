Real things, built.

CS student at FAST-NUCES Lahore with a strong foundation in C++ and a genuine obsession with building things from scratch. I don't wait until I know enough — I pick something hard, figure it out along the way, and ship it.

I've independently built three games in C++ and SFML — a full arcade space shooter with a three-boss mode, a Candy Crush clone with cascading match mechanics, and a Tic Tac Toe game with AI difficulty levels. Things I've shipped.

🚀
Spicy Invaders
C++ · SFML · Raw OOP · No STL

Full arcade space shooter built from scratch. Progressive enemy waves, pixel-perfect collision, three boss fights with unique attack patterns, EMP power-up mechanic, spritesheet-rendered explosions, and a complete audio engine. Every class is mine.

GitHub ↗
🍬
Goated Candy
C++ · SFML · Match-3 · Gravity Sim

Candy Crush clone on an 8×8 grid — smart matching algorithm, real gravity simulation, cascading chain reactions, and four special candy types including Color Bomb. Board refills and animations all handwritten. No engine shortcuts.

GitHub ↗
🎮
Tic Tac Toe AI
C++ · AI · Difficulty Levels · OOP

Tic Tac Toe with a fully playable AI opponent across multiple difficulty levels. The computer adapts its strategy based on selected difficulty — from random moves to near-unbeatable play. Built entirely in C++ with a clean OOP design.

GitHub ↗

4-bit Processor
Digital Logic · LogicWorks · 74LS TTL ICs

Designed and built a working 4-bit processor supporting an 8-instruction ISA using 74LS-series TTL ICs in LogicWorks. A Digital Logic Design semester project — built to actually run programs. Full marks.
